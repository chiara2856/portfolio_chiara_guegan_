# Portfolio de Chiara Guégan

Ouvre `index.html` dans un navigateur pour voir le site. Tous les fichiers nécessaires sont dans ce dossier, y compris la bannière, les visuels de projets, la vidéo et le CV. Une connexion Internet permet de charger les polices Google ; des polices de remplacement sont prévues.

Pour publier le site, envoie le contenu entier du dossier sur ton hébergement en conservant l’arborescence `assets/`.

Les textes, les couleurs et les projets se modifient dans `index.html` et `styles.css`. Les interactions (menu mobile, filtres et fiches de projets) sont dans `script.js`.

La fiche « Les Bon-bons » contient un lien vers le catalogue hébergé en ligne.
